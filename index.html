      How this app calls Pollinations

      You sign in with Pollinations (OAuth code flow with PKCE), so nothing is pasted and the token stays in this tab's sessionStorage. Making a game sends one POST https://gen.pollinations.ai/v1/chat/completions to openai/gpt-5.4-nano (or the model you pick) with your idea, requesting the text scope only. The model is served with paid_only: false, so a game costs a fraction of a Pollen from your own balance. The reply is checked in the browser and then run in a sandboxed frame.
